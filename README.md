# App Calcular Média (Aprimorado)

> Repositório didático: exercício prático de Android nativo com **Java**, desenvolvido e aplicado em sala de aula pelo Prof. Fabricio Curvello.

## Sobre o projeto

Versão aprimorada da calculadora de média: usa **quatro notas** e mostra a situação do aluno com imagem e mensagem.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## O que o app faz

- Quatro campos para as notas.
- Calcula a média e mostra **APROVADO** (média ≥ 7) ou **REPROVADO**, com uma imagem diferente para cada caso.
- Mostra um `Toast` de parabéns quando o aluno é aprovado.

## Conceitos trabalhados em aula

- Organização do código em métodos (`calcularMedia`, `validarSituacao`)
- Estruturas de decisão
- Troca de imagem em tempo de execução (`setImageResource`)
- Listeners de clique

## Tecnologias

- **Java**
- **Android SDK** (Android Studio)
- **Gradle**
- `minSdk 25` / `compileSdk 32`

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/fabcurvello/AppCalcularMediaAprimorado.git
   ```
2. Abra a pasta no **Android Studio** e aguarde a sincronização do Gradle.
3. Execute em um emulador ou dispositivo físico com Android compatível com a API 25 ou superior.
